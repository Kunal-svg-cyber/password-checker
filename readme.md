# 🔐 Cyber Password Strength Checker

A professional **Password Strength Checker** web app built as a **single HTML file** using pure **HTML, CSS, and JavaScript** — designed with a futuristic cybersecurity aesthetic and packed with educational security insights.

> ⚡ Real-time password analysis • Entropy estimation • Crack-time simulation • Secure password generator • Privacy-first design

---

## ✨ Features

### 🔍 Real-Time Password Analysis
- Live password strength detection as the user types
- 5-level strength meter:
  - Very Weak
  - Weak
  - Fair
  - Strong
  - Very Strong
- Animated neon-glow strength bar
- Entropy score calculation in bits

---

### 🛡 Advanced Security Checks
Detects:
- Minimum length issues
- Missing uppercase letters
- Missing lowercase letters
- Missing numbers
- Missing symbols
- Common passwords (top-50 built-in list)
- Sequential patterns (`123`, `abc`)
- Keyboard walks (`qwerty`, `asdf`)
- Weak predictable structures

Dynamic checklist updates in real time with smooth animations.

---

### 🔐 Privacy First
✅ All password analysis happens **100% client-side**  
✅ Passwords are **never stored, transmitted, or logged**  
✅ Includes visible privacy/trust badge

---

### ⚙️ Password Utilities
- Show / Hide password toggle
- Secure random password generator
- One-click copy to clipboard
- Crack-time estimation with animated typewriter effect

---

### 📚 Educational Cybersecurity Sections
Collapsible educational panels explaining:
- How password hashing works
- Salted SHA-256 & bcrypt
- Brute force attacks
- Dictionary attacks
- Credential stuffing
- Rainbow tables
- Why password length matters
- Simple entropy explanations
