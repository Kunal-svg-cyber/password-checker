What is hashing?

When you create an account, reputable services never store your actual password. Instead they run it through a hash function — a mathematical one-way function that transforms your password into a fixed-length string of characters called a digest.

SHA-256 example

The input hello always produces:
2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
Even changing one character produces a completely different hash — this is called the avalanche effect.

Salting

Modern systems add a random string called a salt to your password before hashing. This means even if two users have identical passwords, their hashes differ. Salts defeat precomputed rainbow table attacks.

bcrypt & Argon2

Better than SHA-256 for passwords, these algorithms are intentionally slow and memory-intensive. They include built-in salting and a configurable cost factor — making brute-force cracking exponentially harder as hardware improves.

Brute Force
Tries every possible combination. Defeated by length — each extra character multiplies guesses exponentially.
Dictionary Attack
Tests wordlists of common passwords and words. "Password123!" falls immediately. Avoid real words.
Credential Stuffing
Uses leaked username/password pairs from other breaches. Never reuse passwords across sites.
Rainbow Tables
Precomputed hash-to-password mappings. Defeated by salting — each password must be cracked individually.
Phishing
Tricks users into entering passwords on fake sites. Use a password manager to autofill only on real domains.
Keylogging
Malware that records keystrokes. Kept out by good device hygiene, not stronger passwords.

The entropy formula

Entropy (in bits) = length × log₂(pool_size)

Where pool size is the number of possible characters. Lowercase only = 26. Add uppercase = 52. Add digits = 62. Add symbols = ~95.
